# Python Number Guessing Game

A Python program where the user and computer can guess a secret number.

## About

This project was created as a Python programming exercise to practice
variables, user input, conditional statements, loops, random numbers,
and narrowing down a search range.

## How the Game Works

The program has two modes:

1. The user guesses a number chosen randomly by the computer.
2. The computer guesses a number secretly chosen by the user.

In computer-guessing mode, the program uses the user's feedback
("high" or "low") to narrow down the possible range until it finds
the correct number.

## Features

- User-defined number range
- Two different game modes
- Computer number guessing
- User number guessing
- High/low feedback
- Guess counter
- Search-range narrowing

## Requirements

- Python 3
- No external libraries are required.
